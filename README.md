# SleepNoMore

I build desktop software for Hyprland in Quickshell and tooling for Claude Code. Since September 2026 I have built daily with Claude Code (700+ sessions); the projects below are what came out of it.

## Projects

- [sleepyshell](https://github.com/nninkovic95/sleepyshell): the desktop shell above, in Quickshell and Python with no build step. A test kit previews and deploys a change with a backup and automatic rollback.
- [clawd-band](https://github.com/nninkovic95/clawd-band): a Claude Code mod that puts an animated pixel-art Clawd, the weekly and five-hour usage bars, and their reset countdowns above the prompt.
- [greetd-qsgreeter](https://github.com/nninkovic95/greetd-qsgreeter): a QuickShell login greeter for greetd, reworked from taleroangel's original with a Hyprland setup, full keyboard use, PAM error messages, CI and an AUR package.
- [LLM Wiki](https://gist.github.com/5c92a6f112e50b39d3664722050df089): how I keep a technical knowledge base for my machine with Claude Code, built on Karpathy's pattern.
